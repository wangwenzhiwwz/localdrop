# LocalDrop

在同一局域网内发现附近设备，并通过浏览器发送文件。文件只经过运行 LocalDrop 的本地电脑，不会上传到云端。

## 启动局域网传输

需要 Node.js 22 或更高版本。

```bash
npm install
npm run lan
```

启动后终端会显示本机地址和局域网地址，例如：

```text
本机：http://localhost:4173
局域网：http://192.168.1.24:4173
```

让同一 Wi-Fi 下的手机或电脑打开该局域网地址。保持网页打开后，设备会自动出现在彼此的“附近设备”列表中。

第一次启动时，如果 Windows 防火墙询问是否允许访问，请允许“专用网络”。

## 使用方法

1. 至少使用两台设备打开终端显示的局域网地址。
2. 在左侧选择接收设备。
3. 拖入文件并点击发送。
4. 接收方点击“接受并下载”。

## 说明

- GitHub Pages 版本仅用于查看界面，不能承担局域网设备发现服务。
- 实际传输请运行 `npm run lan`。
- 当前版本使用本地 WebSocket 分片传输，适合同一可信局域网内的快速分享。
